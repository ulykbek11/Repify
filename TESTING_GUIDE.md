## Возможные ошибки и решения

### ❌ "Не удалось подключиться к серверу"

**Проблема:** Фронтенд не может достучаться до бэкенда

**Проверки:**
1. Бэкенд запущен?
   ```bash
   # Должен быть запущен:
   python main.py
   ```

2. IP адрес правильный?
   ```bash
   ipconfig  # проверьте IPv4 адрес
   ```
   
3. Открыть `mobile-app/src/config.js` и проверить:
   ```javascript
   const DEV_API_URL = 'http://192.168.10.50:8000';  // ← правильный IP?
   ```

4. Телефон и ПК в одной WiFi сети?

### ❌ "Встаньте в кадр"

**Проблема:** MediaPipe не видит позу

**Решения:**
- Улучшите освещение
- Отойдите дальше от камеры (2-3 метра)
- Убедитесь, что вы полностью в кадре (от головы до ног)

### ❌ Приседания не считаются

**Проблема:** Угол недостаточный или слишком быстрое выполнение

**Решения:**
- Приседайте глубже (угол колена < 100°)
- Выпрямляйтесь полностью (угол > 160°)
- Делайте паузу в верхней и нижней точках
- Смотрите логи: `🔄 [REP TRACKING] Knee angle: ...°`

### ❌ Баннер не исчезает после калибровки

**Проблема:** Данные не сохранились в Supabase

**Проверка в логах:**
```
[CalibrationScreen] ❌ Supabase update error: ...
```

**Решение:**
- Проверьте подключение к интернету
- Проверьте настройки Supabase
- Повторите калибровку

## Интерпретация результатов калибровки

### Качество калибровки (Quality Score)
- ⭐⭐⭐⭐⭐ (5/5) - Отлично! Все 5 измерений захвачены
- ⭐⭐⭐⭐ (4/5) - Хорошо, 4 измерения
- ⭐⭐⭐ (3/5) - Удовлетворительно
- ⭐⭐ или ниже - Стоит повторить калибровку

### Тип телосложения
- **Бедро:** короткое / среднее / длинное
  - Влияет на допустимый наклон корпуса
  - Длинное бедро → больше наклон разрешен
  
- **Корпус:** короткий / средний / длинный
  - Влияет на баланс при приседаниях
  
### Подвижность
- **Голеностоп (Ankle):** 1-10
  - \> 7 - хорошая подвижность
  - 5-7 - средняя
  - < 5 - ограниченная, возможен отрыв пяток
  
- **Бедро (Hip):** 1-10
  - \> 7 - глубокие приседания доступны
  - 5-7 - стандартная глубина
  - < 5 - ограниченная амплитуда

### Персональные пороги (Thresholds)
После калибровки система адаптирует требования под ваше тело:
- `max_torso_lean_deg` - максимальный наклон корпуса (градусы)
- `min_depth_angle` - минимальная глубина (градусы)
- `max_knee_forward` - насколько колени могут выходить за носки
- `max_heel_lift` - допустимый отрыв пяток

## Что делать дальше

После успешной калибровки система будет использовать ваши персональные пороги при анализе техники упражнений:

1. **Приседания (Squat):**
   - Глубина адаптирована под вашу подвижность
   - Наклон корпуса учитывает длину бедра
   - Отрыв пяток оценивается по вашей подвижности голеностопа

2. **Становая тяга (Deadlift):**
   - Оценка спины с учетом пропорций торса
   - Адаптированные требования к технике

Калибровку рекомендуется повторять раз в 2-3 месяца, так как подвижность может улучшаться с тренировками.
