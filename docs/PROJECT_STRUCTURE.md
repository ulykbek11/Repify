# Структура Проекта MotionIQ

Ниже приведено описание основных папок и файлов проекта.

## 📂 Основные Папки

### `backend/`
**Серверная часть приложения (Python/FastAPI).**
Здесь находится логика API, обработка видео и взаимодействие с базой данных.
- **`main.py`**: Точка входа в серверное приложение. Запускает API.
- **`requirements.txt`**: Список библиотек Python.

### `frontend/`
**Клиентская часть (React Native / Expo).**
Бывшая папка `mobile-app`. Содержит код мобильного приложения.
- **`src/`**: Исходный код интерфейса.
- **`App.js`**: Главный файл приложения.

### `ML/` (Machine Learning)
**Модели и Алгоритмы.**
Здесь хранятся модели машинного обучения и алгоритмы анализа движений (ранее `MotionIQ`).
- **`SQUAT_MODULE/`**: Алгоритмы для анализа приседаний.
- **`DEADLIFT_MODULE/`**: Алгоритмы для анализа становой тяги.

### `data/`
**Данные.**
Хранилище статических данных (например, `exercises.json`).

### `temp_gym_repo/`
**Референсный Репозиторий.**
Временная папка с кодом стороннего проекта "Good-GYM" (использующего RTMPose), который, вероятно, использовался как пример или источник вдохновения. Можно удалить, если он больше не нужен.
